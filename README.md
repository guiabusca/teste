# Guia Busca

Guia de negócios locais (pequenas, médias e grandes cidades) com busca, "aberto agora", WhatsApp, planos pagos e painel administrativo.

- Instruções de uso, publicação de dados e configuração: [`LEIA-ME.md`](LEIA-ME.md)
- Site público: `index.html` · Painel: `admin.html` · Configuração: `config.js`
- Dados publicados: `data/negocios.json` e `data/conteudo.json` (gerados pelo painel ou por `scripts/exportar-dados.mjs`)
